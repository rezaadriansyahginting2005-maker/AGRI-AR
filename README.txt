assets/models/sprayer.glb

CATATAN PENTING ASET
Untuk menjaga agar website langsung mempunyai lima file model, file sabit.glb dari ZIP asal dipakai sebagai arit.glb dan file garpu tanah.glb dipakai sebagai sekop.glb. Periksa bentuk modelnya. Jika keduanya bukan model yang tepat, ganti dengan file GLB arit dan sekop yang benar dengan nama file yang sama.

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder agriAR di VS Code.
3. Jalankan dengan Live Server atau hosting HTTPS.
4. Buat QR Code berisi teks kode di atas (bukan URL).
5. Buka website, pilih alat dari katalog atau scan QR.

CATATAN AR
Model 3D dapat diputar di halaman. Fitur AR memerlukan perangkat/browser yang mendukung dan HTTPS (atau localhost untuk pengembangan).
